# Legal notices and release review

The user chose MIT for original Caps code. The root LICENSE is included in the packaged application. Settings > Legal reads local allowlisted documents from src/legal plus that license; no website or network request is required. The supplemental EULA and Terms do not override MIT permissions. There is no acceptance checkbox claiming to create a separately negotiated contract.

The policy covers the actual desktop implementation, including local media, logs and crash dumps, automatic GitHub updates, automatic Hugging Face metadata requests and explicit model downloads. It does not claim that the developer receives no network-related personal data merely because media is local. Third-party requests disclose network metadata to hosts. There is no account or cloud transcription feature to invent account-termination or server-deletion promises for.

Keep the address current and monitor it for requests. Before distribution, review any additional controller identity/contact details required for the intended jurisdictions; the presence of an email address is not an assertion of blanket GDPR/CCPA/Data Privacy Act compliance. Declaring a private contact route is independent of choosing an open-source license.

The current bundled FFmpeg identifies itself as a GPLv3-enabled Gyan build. Merely adding a notice or licensing Caps's own code under MIT does not fulfill every redistribution obligation for that binary or its libraries. Review the exact corresponding-source and license requirements, NVIDIA runtime redistribution terms, model-weight notices and any font rights before publishing a refreshed full runtime. The notice collector includes the detected build configuration and bundled license texts, but is not an exhaustive dependency-license compliance audit or a source-code offer. No legal opinion or universal liability protection is implied.

Regenerate src/legal/third-party-notices.txt with `scripts/build-legal-notices.py` after changing shipped dependencies. It records installed CPU/CUDA distribution metadata and license files, Python and Electron notices, icon notices and the bundled FFmpeg license output. Actual license texts remain authoritative. Keep native runtime notices in release archives. The app-only update reuses the separately installed speech runtimes and does not relicense or replace them.

Review documents when adding accounts, analytics, crash-report uploads, a website, payments, cloud processing, different update services, or a new controller/contact. A future website needs a policy based on its actual hosting, forms, analytics and server logging, not an automatic copy of this desktop policy. Update the effective date when substantive terms or practices change.
